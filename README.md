# 🚀 Crypto Dashboard  

A **real-time cryptocurrency tracker** built with **Streamlit**, **Plotly**, and the **CoinMarketCap API**. View live prices in INR, market stats, and interactive 24h trends for major cryptocurrencies.  

### ✨ Features  
- 🔥 Live price updates every 30s  
- 💹 Market cap, 24h change %, and trading volume  
- 📈 Interactive Plotly charts  
- 🪙 Supports BTC, ETH, DOGE, BNB, SOL, XRP, ADA, MATIC  
- 🎨 Custom styled Streamlit UI  

### ⚡ Quick Start  
```bash
# Clone & install
git clone https://github.com/yourusername/crypto-dashboard.git
cd crypto-dashboard
pip install -r requirements.txt

# Run app
streamlit run app.py
```

### 🔑 Setup API Key  
1. Get your API key from [CoinMarketCap](https://coinmarketcap.com/api/).  
2. Replace it in `app.py`:  
   ```python
   API_KEY = "YOUR_API_KEY"
   ```
